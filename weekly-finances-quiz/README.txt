INTERMEDIATE SCREENS
After questions 2, 4 and 6: fact guessing/reveal, monthly/weekly budget switching,
and a personal first-step reveal. All insights can be skipped or revisited.
Research figures describe US adults in the 2025 Federal Reserve SHED survey;
source and methodology links are available on each fact panel.
Skipped personal amounts produce a clearly labelled example, not a zero budget.
Generated portraits support the dark/orange visual style; source prompts are
versioned. The original quiz is preserved at /weekly-finances-quiz/classic/.

LIVE CAPTCHA
Cloudflare Turnstile replaces Yandex SmartCaptcha. The widget is managed mode,
English, dark theme, with the quiz_complete action. Worker Siteverify requires
success=true, exact production hostname, and the exact action. Missing keys,
expired or replayed tokens, provider errors and mismatches block completion.
The API accepts a token only. Answers and amounts never leave the tab.
Public settings are in wrangler.jsonc. TURNSTILE_SECRET must be a Worker secret,
never a source file or browser value. Preserve secret bindings during deploys.
Build the site module with npm run build:worker before deploying.
GitHub Pages remains an explicit static preview without live verification.

ANALYTICS
Optional Metrica, disabled unless a real counter is configured and user opts in.
No Webvisor, clickmap or automatic link tracking. No answer values or amounts
are sent. Campaign params and funnel event names may be sent after consent.
No purchase event is generated by this quiz. App Store clicks are not purchases.
APP_STORE_CAMPAIGN_URL accepts only HTTPS apps.apple.com links for id6756235224.
Use a real campaign link from App Store Connect, with its provider token.

PRIVACY AND SCOPE
Quiz answers are memory-only and reset on reload. The optional money calculation
is (monthly income - committed spending - planned savings) * 12 / 52.
Negative balances remain a gap; missing figures are not replaced with zero.
No LLM, account, bank connection, email collection, trial or payment checkout.
The personal plan is a rule-based starting routine, not financial advice or
a psychometric score. Answers are not transferred into the app.
