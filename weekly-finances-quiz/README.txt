Weekly Finances — English acquisition quiz
Updated 5 November 2026. Design preview; no ad spend.

PUBLIC TEST VERSION
https://muchosun.github.io/weekly-finances-quiz/
GitHub Pages serves the static preview from /docs on main. The optional Actions
workflow can publish after switching Pages to the workflow build type.
CAPTCHA and analytics are not active on this public design preview.

QUICK PREVIEW
Open preview.html in a browser. It is a standalone local design preview.
It has 7 questions, 3 optional interactive insights, four goal-based result paths
and optional browser-only amounts. Choice questions advance automatically.
CAPTCHA is clearly marked as not connected. No verification is simulated.

INTERMEDIATE SCREENS
After questions 2, 4 and 6: fact guessing/reveal, monthly/weekly budget switching,
and a personal first-step reveal. All insights can be skipped or revisited.
Research figures describe US adults in the 2025 Federal Reserve SHED survey;
source and methodology links are available on each fact panel.
Skipped personal amounts produce a clearly labelled example, not a zero budget.
Generated portraits support the dark/orange visual style; source prompts are
versioned. The original quiz is preserved at /weekly-finances-quiz/classic/.

LIVE CAPTCHA
Configure the public client key and private server key in the hosting environment,
not in source or a browser field. .env.example contains variable names only.
Node does not load .env files automatically: use your deployment secret store or
Node's --env-file support with a local, ignored file you fill in yourself.
Set PREVIEW_MODE=0, NODE_ENV=production, HOST=0.0.0.0,
PUBLIC_ORIGIN=https://your-domain and SMARTCAPTCHA_EXPECTED_HOST=your-domain.
For a local live check, add localhost/127.0.0.1 to the CAPTCHA allowed hosts and
use its exact returned host including port in SMARTCAPTCHA_EXPECTED_HOST.

Only /api/complete calls the validation API. It accepts a token only, never quiz
answers or financial figures. Requires Yandex status=ok AND an exact host match.
Missing keys, expired tokens, upstream errors and timeouts block completion.
The standard widget is in English and handles expiry / network / JS errors.
Real widget rendering and real token validation remain untested without keys.
The production dist/ application needs the Node API or an equivalent server
route. The generated Pages build explicitly enables design preview mode,
avoids API calls and shows that live verification is not connected.
Do not use the design preview as a live ad destination.

ANALYTICS
Optional Metrica, disabled unless a real counter is configured and user opts in.
No Webvisor, clickmap or automatic link tracking. No answer values or amounts
are sent. Campaign params and funnel event names may be sent after consent.
No purchase event is generated by this quiz. App Store clicks are not purchases.
APP_STORE_CAMPAIGN_URL accepts only HTTPS apps.apple.com links for id6756235224.
Use a real campaign link from App Store Connect, with its provider token.

PRIVACY AND SCOPE
Quiz answers are memory-only and reset on reload. The optional money calculation
is (monthly income - committed spending - planned savings) * 12 / 52.
Negative balances remain a gap; missing figures are not replaced with zero.
No LLM, account, bank connection, email collection, trial or payment checkout.
The personal plan is a rule-based starting routine, not financial advice or
a psychometric score. Answers are not transferred into the app.
